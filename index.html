Jeu de données

Le jeu de base (base de Le Châble, 50 descentes tracées sur le relief réel) est fixe : il est toujours le même et reste disponible à tout moment. Vous pouvez travailler sur un autre jeu (nouvelles descentes, base déplacée, import JSON), puis revenir au jeu de base d’un clic.

Nouvelles descentes générées autour de la base (latitude / longitude), sur le relief réel téléchargé (connexion requise) ou synthétique. « Placer la base sur la carte » génère les descentes autour du point cliqué.

Descentes

Format JSON : { origin:{lat,lon}, base:{x,y,alt}, runs:[{code,name,top:{x,y,alt},bottom:{x,y,alt},vert,skiMin,path?}], timeMatrix? } (x, y en km depuis la base, vers l’est / le nord). Si timeMatrix (minutes, nœuds : base, sommets, fonds) est fourni, il remplace le calcul par distance. Colonne Jour : descentes réalisables aujourd’hui (seules utilisées par l’optimisation).
